# Pinned as a known-compatible set, not open ">=" bounds: the ML stack here
# moves fast enough that the latest release of each, resolved independently,
# does not necessarily work together. Specifically —
#   - torch/torchaudio must be an exact matched pair (torchaudio's release
#     cadence has fallen behind torch's; pip will happily install torch 2.14
#     next to torchaudio 2.11, which do not agree on a shared API).
#   - torchaudio 2.4.x is the newest line that still ships the classic
#     I/O API (AudioMetaData, load, info) that pyannote.audio depends on —
#     newer torchaudio releases are migrating that surface to a separate
#     `torchcodec` package pyannote does not yet use.
#   - pyannote.audio is pinned below 4.0: the 4.x pipeline pulls in a chain
#     of additional gated "community" scoring models beyond the two gates
#     documented in this file's README; 3.x's simpler embedding+segmentation
#     pipeline needs only those two.
#
# Swap the two torch lines for a CUDA build on a GPU host, e.g.:
#   pip install torch==2.4.1 torchaudio==2.4.1 --index-url https://download.pytorch.org/whl/cu121
